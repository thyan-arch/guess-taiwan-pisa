# 猜猜臺灣排第幾 · PISA 科學主測年資料專題

一個互動網頁：用 PISA 三個科學主測年（2006、2015、2025）的官方資料，
讓人**先猜再看答案**——猜臺灣在成績、自信、動機、性別、城鄉、課堂與十九年趨勢上的世界排名。

**線上版：https://thyan-arch.github.io/guess-taiwan-pisa/**

由 [LIS 情境科學教材](https://lis.org.tw) 製作。

## 網站

`web/index.html`（部署版在 `docs/index.html`）是一個**單檔、零相依的靜態頁面**（約 218 KB，logo 以 data URI 內嵌），
直接用瀏覽器開啟即可，不需要伺服器或建置工具。

- 27 個問題，分 7 個分類頁：成績 / 自信 / 動機 / 性別 / 城鄉 / 課堂 / 趨勢
- 滑桿猜排名或數值 → 揭曉時顯示各國分布圖（或跨屆折線圖）、OECD 平均、日韓美新芬對照、原始表號
- 計分、判定、連擊、章節徽章；作答紀錄存在瀏覽器 localStorage
- 淺色 / 深色 / 跟隨系統三種配色，深色模式對比全數通過 WCAG AA
- 遵循 LIS 品牌書與設計系統 v1.0（色票、字級、8pt 間距、圓角、零陰影）

## 重新建置

```bash
bash build/fetch_raw.sh          # 從 OECD 重新下載原始資料表（約 57 MB）
python3 build/extract.py         # 抽取 → data/pisa.json、pisa_long.csv
python3 build/quiz.py            # → data/taiwan_profile.json、quiz.json
python3 build/web_data.py        # → data/web_data.json（一般題）
python3 build/trend_data.py      # → data/trend_data.json（趨勢題）
python3 build/make_site.py       # 組裝 → web/index.html 與 docs/index.html
```

需要 `openpyxl`、`xlrd`。題目文案集中在 `build/qtext.py`。

`raw/` 未納入版控：那是 OECD 的出版品，且檔案較大。`build/fetch_raw.sh` 會依
`raw/SOURCES.md` 記錄的 StatLink 與 DOI 重新下載，每個檔案的來源都可追溯。

## 為什麼是這三年

PISA 每三年一輪，三個領域輪流當主測領域。**只有主測年才會施測該領域的完整態度問卷**
（樂趣、自我效能、動機、職涯期待）。科學主測年＝ **2006、2015、2025**。
（沒有「PISA 2019」；PISA 2018 是閱讀主測，結果於 2019 年 12 月公布。）

台灣 2006 年首次參加 PISA，因此三個科學主測年全數有資料。
PISA 2025 結果於 **2026-09-08** 公布（Volume I）；Volume II 預計 2026-12-01。

## 指標涵蓋（79 個「年度×指標」）

- **成績**：科學／閱讀／數學／運算問題解決平均分數、標準差、P10／P90、高低分差距、
  三個科學子項、未達基礎水準比例、頂尖學生比例、環境科學子量表
- **態度**（各屆問卷不同）
  - 2006：一般興趣、享受科學、工具性動機、未來導向動機、自我效能、**自我概念**、
    科學的一般價值／個人價值、支持科學探究、對學習科學主題的興趣、課外科學活動
  - 2015：享受科學、對各類科學主題的興趣、工具性動機、自我效能、課外科學活動、**知識論信念**
  - 2025：好奇心、毅力、**成長心態**、對科學本質的信念、認知彈性、主動求助、目標設定、
    享受科學、科學課的認知啟動、學校歸屬感、對學校的態度、生活滿意度
- **職涯**：30 歲期待從事科學相關工作的比例（總計＋科學工程／醫療／資通訊／技術員四類）、
  職業想法不明確比例、家長從事科學工作比例
- **公平性／性別**：社經地位解釋力、社經前後段分數差、男女分數
- **學校（2025）**：教師支持、家庭支持、AI 使用、功課時數、科學課數位干擾
- **環境**：環境議題認識、擔憂、樂觀、永續責任感（2006）；環境認識、個人／集體效能感、
  環境職涯期待（2025）

## 資料判讀紅線（做網頁時務必照做）

1. **指數類（kind=`index`）是「該屆 OECD 平均＝0、標準差＝1」的標準化分數。**
   跨屆的指數「數值」不可直接相減當成變化量（每屆重新標準化）；
   **跨屆請比排名／百分位**，或引用 OECD 自己算的 change 表。
2. **排名一律標明母數**。各屆參與數不同：2006 = 57、2015 = 73、2025 = 91 個國家／經濟體，
   且部分指標有國家未作答（母數會少於該屆總數，`n` 欄已逐題記錄）。
3. **台灣在 OECD 表中名稱為 Chinese Taipei**，非 OECD 會員，OECD 平均不含台灣。
4. 少數系統有抽樣警示（原表以 `*` 標記，如美國、加拿大、荷蘭、紐西蘭、挪威、阿爾巴尼亞），
   本庫已去除星號但差異需注意。
5. `B-S-J-Z (China)` = 北京／上海／江蘇／浙江四省市，不等於中國全國；
   2015 年為 `B-S-J-G (China)`（廣東），本庫已合併名稱但兩者抽樣範圍不同。
6. 「意外指數」= 台灣在該指標的百分位 − 台灣在該屆科學成績的百分位。
   正值代表「這個面向比成績表現差」，是設計題目的挑選依據，**不是** OECD 的官方指標。
